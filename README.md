# 都立新宿高校 米国同窓会 2026 ウェブサイト

2026年9月6日（日）に開催された「東京都立新宿高等学校 米国同窓会」のレポート・写真館用ウェブサイトのドラフトです。
招待されたメンバー（同窓生・関係者）が見やすく、スマートフォン・PCのどちらでも美しく表示されるレスポンシブデザインになっています。

---


## ✏️ 編集・カスタマイズ方法

### 1. テキスト（挨拶・日時・メッセージ等）の変更
`index.html` をテキストエディタ（VS Code, メモ帳など）で開きます。
各セクションに `<!-- 【編集エリア】... -->` というコメントが付いているため、その中の文字を書き換えるだけで反映されます。

- **開催概要 (`#overview`)**: 開催都市名、会場名、参加人数、期生情報
- **ご挨拶 (`#about`)**: 主催者からのメッセージやお礼の言葉
- **当日のハイライト (`#program`)**: 当日のタイムテーブルや行われた企画
- **参加者の声 (`#messages`)**: 参加された方の感想やコメント
- **次回案内・連絡先 (`#contact`)**: 次回開催予定時期、幹事のメールアドレス、LINEグループ名など

### 2. 写真の差し替え
当日の実際の写真（JPG や PNG）を `assets/images/` フォルダ内に入れます。

例: `assets/images/photo1.jpg` を入れた場合、`index.html` の写真部分を次のように変更します:
```html
<!-- 変更前 -->
<img src="assets/images/group-photo.svg" alt="集合写真">

<!-- 変更後 -->
<img src="assets/images/photo1.jpg" alt="2026年 米国同窓会 集合写真">
```

### 3. テーマカラーの変更
学校カラーやお好みに合わせて色を変えたい場合は、`assets/css/style.css` の冒頭にある `:root` を編集してください。

```css
:root {
  --primary-navy: #162447;      /* メインの濃紺 */
  --accent-gold: #c59b27;       /* アクセントのゴールド */
  --bg-main: #f8fafc;           /* 全体背景色 */
}
```

## 🌐 メンバーへの限定公開・共有方法

招待メンバー限定で公開する際のおすすめの方法です：

1. **限定公開URL（無料・手軽）**:
   - **Netlify** / **Vercel** / **GitHub Pages**: このフォルダをアップロードするだけで即座にWebサイトURLが発行されます。
   - ※ URLを知っている人のみ閲覧可能（検索エンジンのインデックス拒否設定済み）
2. **パスワード保護をつけたい場合**:
   - Netlify の「Password protection」機能や、静的サイト用の簡易パスワードゲート（JavaScriptまたはBasic認証）を導入できます。
